# Async quotes scrapper
A standalone Asynchroious web scrapper build with:
-python
-httpx
-Besutifulsoup4 
-asyncio

# Features
-Asynchronous httpx requests
-HTML parsing using beautifulpool
-configurable timeout
-Retry with exponential backout
-Request arte limiting
-JSON output

# setup
-Create a virtual environment
python -m venv venv

-Activate it in windows
venv\Scripts\activate

-install dependencies
pip install -r requirements.txt

-Run
python .\scrapper.py
